# 📊 Dashboard RAIS — Observatório Econômico de São José dos Campos


## 📈 Estrutura do Dashboard

O painel foi organizado em **sete páginas**, permitindo explorar diferentes aspectos da economia municipal.

### 1. Visão Geral

Apresenta os principais indicadores da base RAIS, proporcionando uma visão consolidada do mercado de trabalho formal de São José dos Campos.

### 2. Análise Setorial

Permite comparar os diferentes setores econômicos, identificando sua participação na geração de empregos formais e a concentração das atividades produtivas.

### 3. Setores Econômicos — CNAE 2.0

Apresenta a distribuição das atividades econômicas conforme a Classificação Nacional de Atividades Econômicas (CNAE 2.0).

A análise permite identificar as atividades de maior representatividade, com destaque para a indústria aeronáutica.

### 4. Análise por Subsetores

Examina a distribuição dos vínculos empregatícios entre os subsetores econômicos, permitindo identificar as atividades com maior participação no mercado de trabalho municipal.

### 5. Natureza Jurídica

Apresenta a distribuição dos estabelecimentos e vínculos empregatícios conforme sua natureza jurídica, permitindo compreender a composição jurídica das organizações analisadas.

### 6. Tamanho das Empresas

Analisa a distribuição dos vínculos empregatícios de acordo com as faixas de tamanho dos estabelecimentos.

Essa visualização permite comparar a participação dos diferentes portes na estrutura de empregos formais do município.

### 7. Comércio Exterior

Apresenta indicadores de exportação, importação e saldo comercial de São José dos Campos, utilizando informações do Comex Stat referentes ao ano de 2024.

A análise inclui os principais produtos comercializados internacionalmente, classificados pela posição SH4.
